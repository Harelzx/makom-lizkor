# סקירת טיפוגרפיה וקריאות — 9.10.2026

## מה השתנה ולמה

טקסט רגיל עלה מ־15 ל־16px, סיפורים מ־17 ל־18px, תוויות מ־14 ל־15px וקרדיטים מ־11–13 ל־14px. כותרות ראשיות נעות בין 32 ל־40px וכותרות מקומות בין 26 ל־30px, עם גובה שורה שמאפשר כותרת עברית ארוכה. הגדלים הם ברירות המחדל לפני הגדלת טקסט של המשתמש, ואינם גדלים אוטומטית בלי גבול במסך גדול.

הסולם המעודכן נמצא ב־[design-system.md](design-system.md) וב־`src/index.css`. רכיבי הדיאלוג, השדות, ההסברים והכפתורים שמשמשים את המסכים הותאמו אליו. שדות קלט נשארים בגודל 16px גם במחשב. הודעות שגיאה, בטיחות, פרטיות ומצב שליחה הן טקסט קריא, ולא קרדיט זעיר.

בכרטיס מקום נוסף אזור פעולות עם קו עדין לפניו ואחריו. ניווט בשורה אחת, שיתוף ושמירה בשורה נפרדת. הפרדה דומה נוספה לפעולות באודות, באימות מייל, בהודעות השליחה ובניהול. טקסט ארוך מוגבל לרוחב קריאה; שמות וכתובות ברשימה ובחיפוש יכולים לתפוס שתי שורות.

בהגדלת הטקסט פי שניים במסך 320px נמצאה חפיפה ממשית בשלבי הטופס. הבדיקה נכשלה לפני התיקון. כעת המספרים עוברים מעל שמות השלבים כשהשטח אינו מספיק; ברוחב רגיל הם נשארים באותה שורה ומיושרים לפסי ההתקדמות.

## מסכים שנבדקו חזותית

התצוגה נבדקה בדפדפן המקומי ונשמרו צילומי המסכים עצמם. נתוני המקומות הם נתוני הפיתוח הקיימים ואינם תוכן מאושר להשקה.

| מסך | מה נבדק / שונה |
|---|---|
| מפה ורשימת מקומות | היררכיית שם/כתובת, שתי שורות לשמות ארוכים, כותרות קבוצה וקו הפרדה; מחשב ונייד |
| כרטיס מקום | סיפור 18px, כתובת 16px, קרדיט 14px, אזור ניווט/שיתוף/שמירה; בוקר ולילה |
| חיפוש | תוצאות 16px, מידע משני 14px, חלון שנכנס למסך הטלפון |
| קהילות וכרטיס קהילה | הסבר, סטטוס, סיפור, קרדיטים וסעיפי תקומה/זיכרון |
| מסע 232 | פתיחת המסע ועצירה, סיפור וכתובת, הפרדת כפתורי הבקרה |
| אודות | כותרת, סיפור המיזם, פעולות; נייד ומסך 1920×1080 |
| תנאים, פרטיות, נגישות, קרדיטים | טקסט ארוך 16px, ריווח וסעיפים; התוכן המשפטי לא שונה |
| הוספת מקום | שלושת השלבים, תוויות, שגיאות, הסברים והודעות פרטיות; 320/390/1280px |
| בקשת תיקון/הסרה | תוויות ושדות בטופס הקיים, טקסט הסבר ופרטיות; לא נשלחה בקשה |
| מעקב | הצעת דמה מקומית במצב ממתינה וקישור שאינו תקין |
| אימות מייל | חלון ההסבר לפני אישור כתובת; לא נשלח מייל |
| ניהול | תור עם הצעת דמה, כותרות, סיפור ופעולות מופרדות; לא אושר תוכן |

כותרות העיתון והפתיחה שומרות על הטיפוגרפיה הייעודית שלהן. ייחוס ספקי המפה וקיצורי מקלדת נשארים קומפקטיים. רכיבי ספרייה שאינם מופיעים במסכי האתר אינם הוכחה למסך נוסף שנבדק.
